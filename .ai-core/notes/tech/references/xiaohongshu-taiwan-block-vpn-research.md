# 小紅書台灣封鎖現況與 VPN/Cookie 抓取調研

## 研究問題

1. 小紅書（xiaohongshu.com / xhslink.com）在台灣是否被封鎖、原因為何、有無免費/合法替代連線方式
2. 若需 VPN 翻牆進中國大陸，目前哪些方案穿透力強且 CP 值高；近期中國打擊 VPN 是否影響可用性
3. IG/FB/X-NSFW 等平台的 cookie 登入牆抓取難易度

---

## 一、小紅書台灣封鎖現況

**封鎖事實**：內政部警政署刑事局於 2025-12-04 記者會宣布，指小紅書涉及 1,706 件詐騙案件、財損逾 2.7 億元，且國安局 15 項資安檢測**全數未通過**，即起對小紅書發布**停止網域解析（DNS）+ 限制接取**命令，暫定期間 **1 年**（約到 2026-12）。

**法律面**：內政部明確表態——一般民眾自行用 VPN 或修改 DNS 繞過封鎖**不會觸法**，政府立場是「強烈建議卸載以策安全」，但沒有強制個人不得使用。

**免費合法替代方案（不需要 VPN）**：
封鎖手法是 DNS 層級（停止解析），因此只要把裝置 DNS 改成公共 DNS 即可繞過：
- Google DNS：`8.8.8.8` / `8.8.4.4`
- Cloudflare DNS：`1.1.1.1` / `1.0.0.1`

手機/電腦系統設定內修改 DNS 即可，**免費、零風險、不需 VPN**。此法只解決「連上小紅書網域」，與下方中國境內翻牆是兩回事。

## 二、中國 VPN 翻牆現況（若未來需要，例如訪問純境內服務）

**⚠️ 重要澄清**：連小紅書本身不需要翻牆進中國大陸——只是台灣單方面 DNS 封鎖。VPN 翻牆議題只在「額外需要存取中國大陸境內服務」時才相關。

**2026 年打擊力道（近期顯著升級）**：
- 2026-04 起中國禁止承載 VPN/代理業務，中央網信辦＋工信部＋三大電信運營商聯合對使用端監控
- 2026-03 多地警方對一般 VPN 使用者展開入戶搜查、當場拘押、公開處罰
- 2025-11 工信部推進國行手機 VPN 功能系統性限制，華為率先測試，預計 2026 年擴展至小米/OPPO/vivo
- 截至 2026-07-11，超過 30 款代理軟體已被列入 VPN 識別名單，且識別規則持續更新（7 月初已多次更新）
- 中國境內使用 VPN 依現行政策存在法律風險

**技術面觀察**：VLESS + Reality 協定路線目前相對抗封鎖能力較強；但這類排名/推薦**保鮮期很短**（可能數週內失效）。

**結論（不推薦具體品牌）**：目前沒有任何 VPN 品牌能被認定「長期最強穿透力」——识别名单每週更新、抓人力度持續升級，任何「CP 值最高」推薦都可能在你買了之後就失效。若確有需求，建議：
1. 優先選可自建的協定型方案（如 VLESS+Reality 自架），而非依賴品牌商業 VPN 的固定節點
2. 避免長期訂閱單一品牌，保留隨時更換的彈性
3. 若只是連小紅書——**完全用不到這層**，改 DNS 即可

## 三、社群平台 cookie 登入牆抓取難易度（對應下載功能 C 路 gallery-dl 引擎）

依現有下載稽核（`agents/0-download-audit.md`）與本次調研交叉比對：

| 平台 | 登入牆抓取難易度 | 備註 |
|---|---|---|
| X（含 NSFW） | 中等偏易 | Netscape cookie 格式放 `config/cookies/x.txt` 即可，gallery-dl 原生支援佳 |
| Instagram | 中等 | 需完整 session cookie，且 IG 反爬蟲策略常變動，穩定性不如 X |
| Facebook | 中等偏難 | cookie 抓取本身不難，但 FB 對自動化存取偵測較嚴，短期內容易被限流 |
| 小紅書 | 易 | 一旦繞過 DNS 封鎖後，登入牆本身用 cookie 即可正常抓取（本專案已支援全圖集） |

**取得方式**：瀏覽器登入後用擴充套件匯出 Netscape 格式 cookie 檔，放到 `config/cookies/{platform}.txt`（README 已有教學）。難度排序（易→難）：小紅書 ≈ X < Instagram < Facebook。

---

## 結論摘要

1. **小紅書：改 DNS（8.8.8.8 或 1.1.1.1）即可，免費、合法、不需 VPN**
2. **VPN 翻牆只在需要額外存取中國境內服務時才相關**，且 2026 年中國查緝力道空前嚴厲，任何品牌推薦保鮮期短，不建議長期押注單一商業 VPN
3. **Cookie 抓取**：X 最容易、小紅書繞過封鎖後也容易，IG/FB 較不穩定但仍可行
